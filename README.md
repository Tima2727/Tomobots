# Tomobots: Роевая система роботов для поиска людей в завалах

**Tomobots** — это инженерный проект по разработке роя компактных и дешевых автономных роботов, предназначенных для первичной разведки в зонах обрушений зданий и землетрясений. Система призвана заменить дорогостоящие и крупногабаритные платформы, обеспечивая быструю локализацию пострадавших даже в труднодоступных «карманах» и щелях.

## Основные особенности

* **Роевая архитектура**: Массовое развертывание сотен простых устройств делает систему устойчивой к потере отдельных единиц.
* **Уникальная проходимость**: Роботы имеют тарелкообразную форму (диаметр 8-10 см) и симметричную конструкцию, позволяющую продолжать движение даже после переворачивания.
* **Низкая себестоимость**: Ориентировочная стоимость в сотни раз меньше аналогов.
* **Ретрансляционная сеть**: При обнаружении человека роботы формируют цепочку передачи радиосигнала до поверхности без необходимости в сложной навигации.

## Технические характеристики прототипа

| Параметр | Значение |
| :--- | :--- |
| **Габаритный диаметр** | 10 см |
| **Масса** | 32 г |
| **Вычислительный модуль** | ESP-12 (ESP8266) |
| **Время работы** | ≈ 25 мин |
| **Материал корпуса** | PLA |

## Алгоритм работы

1.  **Развертывание**: В зону завала запускается партия из ~100 роботов.
2.  **Зондирование**: Роботы выполняют циклы коротких взлетов и хаотичных перемещений.
3.  **Активация**: Пострадавший нажимает высококонтрастную кнопку на роботе.
4.  **Режим маяка**: Активированный робот включает яркую RGB-подсветку и начинает передачу сигнала.
5.  **Локализация**: Ближайшие роботы ретранслируют сигнал на поверхность, где система антенн определяет примерное местоположение цели.
